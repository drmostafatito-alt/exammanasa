# منصة الامتحانات على Cloudflare (خطة مجانية 100%)

> **القاعدة:** كل ما في هذا الدليل يعمل على Cloudflare Free — لا يطلب الدفع في أي خطوة، وإن ظهر طلب دفع فأنت في الصفحة الخطأ.

## المعمارية

```
الطالب (متصفح)
   │
   ▼  https://exammanasa-platform.<حسابك>.workers.dev  (أو نطاق مخصص مجاني)
Cloudflare Worker  (src/worker.js — منطق واحد يخدم الجميع)
   ├── ملفات ثابتة (public/) — واجهة الطالب + لوحة التحكم عبر CDN
   ├── /api/* — جلسات الامتحان والتصحيح (المفاتيح داخل حزمة الـWorker فقط، لا تُرسل للطالب أبدًا)
   ├── /<slug> — صفحة كل معلم (مثل /mostafa) بعلامته وألوانه
   ├── KV — المعلمون + حساب المسؤول (PBKDF2) + النتائج الأخيرة + منع التكرار
   └── Google Apps Script (اختياري) — تمرير النتائج إلى جدول Google Sheets القائم
```

- **بنوك الأسئلة** (‎`src/data/banks.json`‎ — 1347 سؤالًا / 75 امتحانًا) تُضمَّن في حزمة الـWorker (‏250KB مضغوطة فقط، ضمن حد الخطة المجانية 1MB).
- **المفاتيح لا تظهر** في أي استجابة قبل التسليم؛ التصحيح على الخادم فقط، والخلط بذرة عشوائية لكل جلسة (نفس خوارزمية تطبيق GAS الأصلي حرفيًا — مثبت بالاختبارات).
- **الطلاب لا يستخدمون رابط GAS إطلاقًا** — نقطة الدخول هي رابط Cloudflare.

## خطوات النشر (مرة واحدة، ~10 دقائق)

### 1) المتطلبات
- حساب Cloudflare مجاني + Node 18+ (على جهازك أو GitHub Codespaces).
- من مجلد `cloudflare/`:
```bash
npm install
npx wrangler login     # يفتح صفحة تفويض مجانية
```

### 2) إنشاء مساحة KV (مجانية)
```bash
npx wrangler kv namespace create PLATFORM_KV
```
انسخ الـ`id` الظاهر وضع مكان `00000000000000000000000000000000` في `wrangler.jsonc`.

### 3) النشر
```bash
npm run build:banks   # (اختياري — مولد مسبقًا) يعيد توليد banks.json من ملفات .gs
npx wrangler deploy
```
ستحصل على رابط مثل: `https://exammanasa-platform.<حسابك>.workers.dev`
- صفحة المعلم الافتراضي: `…/mostafa`
- لوحة التحكم: `…/admin`

> الرابط يعمل بصيغة `<name>.workers.dev`. إن كنت تفضل لاحقة `pages.dev` تحديدًا فالمنصة متوافقة مع Cloudflare Pages أيضًا (نفس مجلد public + دالة داخل functions/)، لكن Workers هو المسار الموصى به رسميًا من Cloudflare ويدعم كل الميزات المستخدمة هنا.

### 4) حساب المسؤول (أول تشغيل)
افتح `…/admin`:
- إن لم يوجد حساب: تظهر شاشة **الإعداد الأولي** — أنشئ الحساب ببريدك الإلكتروني وكلمة المرور الابتدائية، ثم **غيّرها** من متصفحك لاحقًا بإعادة الإعداد… لا: كلمة المرور تُخزن PBKDF2-مُلَحًّا في KV ولا تُرسل لأي واجهة.
- أو زرع الحساب مسبقًا عبر أسرار (بدون شاشة إعداد):
```bash
npx wrangler secret put ADMIN_INITIAL_EMAIL
npx wrangler secret put ADMIN_INITIAL_PASSWORD
```
(عند وجودهما يُنشأ الحساب تلقائيًا عند أول محاولة دخول.)

**كلمة المرور الابتدائية لا تُكتب في أي ملف/كود/GitHub** — تُدخل مرة واحدة عبر الشاشة أو أمر `wrangler secret`.

### 5) (اختياري لكن موصى به) ربط النتائج بجدول Google Sheets القائم
1. في مشروع Apps Script الحالي (الذي يحوي `doPost` الجديد): من ⚙️ إعدادات المشروع → خصائص البرنامج النصي → أضف خاصية:
   - الاسم: `PLATFORM_RESULTS_SECRET` — القيمة: سر عشوائي طويل (مثلًا 32 حرفًا).
2. أعد نشر تطبيق الويب: Deploy → Manage deployments → ✎ → New deployment → Web app → Execute as: Me / Who has access: **Anyone**.
3. في Cloudflare:
```bash
npx wrangler secret put GAS_WEBAPP_URL        # رابط /exec الكامل
npx wrangler secret put GAS_RESULTS_SECRET    # نفس قيمة PLATFORM_RESULTS_SECRET
```
من هذه اللحظة تُضاف كل نتيجة إلى جدول النتائج نفسه (مع عمود جديد «المعلم») **وتُحفظ أيضًا في KV** كنسخة احتياطية. إن لم يُضبط الربط: تعمل المنصة كاملة وتُحفظ النتائج في KV فقط.

### 6) أسرار إضافية (اختياري)
```bash
npx wrangler secret put SESSION_SECRET   # توقيع الجلسات — وإلا يُولد تلقائيًا ويُخزن في KV
```

## إدارة المعلمين (من لوحة التحكم)
تبويب «المعلمون»: إضافة/تعديل معلم (الاسم، الهاتف، واتساب/فيسبوك/تيك توك، صورة، نبذة، ألوان، طلب رقم الهاتف)، توليد slug ورابط عام تلقائيًا، تفعيل/تعطيل، نسخ الرابط، حذف. كل المعلمين يشاركون نفس بنوك الأسئلة والامتحانات — الفرق هو الهوية والألوان والروابط فقط. الصفحة العامة لكل معلم: `…/<slug>`.

| كتابات KV | 1000/يوم | ~3 كتابات لكل تسليم (نتيجة+منع تكرار+فهرس) → حتى ~300 تسليم/يوم، ثم تستمر النتائج بالظهور للطالب وتُحفظ في Sheets إن كان الربط مفعّلًا |
| قراءات KV | 100 ألف/يوم | قليل جدًا (ملفات المعلمين مخبأة 5 دقائق على الـCDN) |

| الأصول الثابتة | غير محدودة عمليًا | ملفات صغيرة عبر CDN |

## الأمان (مطبق ومُختبَر)
- التصحيح على الخادم حصرًا؛ لا مفاتيح في أي استجابة/HTML/JSON قبل التسليم (مُختبَر آليًا).
- جلسات امتحان موقعة HMAC-SHA256 بصلاحية 6 ساعات؛ رفض التلاعب والتسليم الناقص؛ منع إعادة التسليم (Cache + KV).
- لوحة التحكم: بريد/كلمة مرور (PBKDF2-SHA256، 120 ألف تكرار، ملح عشوائي)، كوكي HttpOnly+Secure+SameSite=Strict، حماية CSRF (ترويسة خاصة)، تحديد معدل محاولات الدخول.
- ترويسات أمنية على كل الاستجابات + CSP صارم + تعقيم كل المخرجات (esc) + التحقق من روابط التواصل (http/https فقط).
