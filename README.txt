منصة الامتحانات التعليمية — Master Template (متعددة المواد)

المواد:
1) علم النفس (المرحلة الثانوية) — 6 وحدات / 24 امتحان موضوع / 6 امتحانات شاملة = 30 امتحانًا / 840 سؤالًا.
2) الفلسفة والمنطق (أولى ثانوي 2027) — ترمين:
   - الترم الأول: 4 فصول / 9 تدريبات + 3 امتحانات شاملة = 12 امتحانًا / 555 سؤالًا مُتحققًا منه.
   - الترم الثاني: فصلان / 4 تدريبات = 4 امتحانات / 234 سؤالًا مُتحققًا منه (سؤال واحد مستبعد غامض).

المحتويات:
- Code.gs          منطق الخادم (التوجيه، الإعدادات، فتح الامتحانات، التصحيح، النتائج، لوحة التحكم، روابط التواصل)
- Config.gs        ثابت الإصدار فقط
- Data.gs          بنك أسئلة علم النفس (30 امتحانًا / 840 سؤالًا) — محمي ولا يُعدَّل
- PhiloData.gs     بنك الفلسفة والمنطق — الترم الأول (مُتحقق منه بالكامل)
- PhiloTerm2Data.gs بنك الفلسفة والمنطق — الترم الثاني (مُتحقق منه بالكامل)
- Index.html       واجهة الطالب (عربية RTL، متعددة المواد، ترمين)
- Admin.html       لوحة تحكم المدرس (متعددة المواد، ترمين، روابط التواصل)
- AUDIT_PHILOSOPHY.md        سجل تدقيق إجابات الفلسفة والمنطق — الترم الأول
- AUDIT_PHILOSOPHY_TERM2.md  سجل تدقيق إجابات الفلسفة والمنطق — الترم الثاني

المزايا:
- رابط Web App واحد للطلاب.
- اختيار المادة أولًا (علم النفس / الفلسفة والمنطق).
- علم النفس: وحدة → موضوع/شامل (كما هو، بدون تغيير).
- الفلسفة والمنطق: ترم (الأول/الثاني) → قسم → فصل → تدريب = امتحان 20 سؤالًا،
  + امتحان شامل لكل قسم + امتحان شامل للمادة (الترم الأول فقط).
- الاختيارات تُعرض بالحروف العربية (أ، ب، ج، د) مرة واحدة فقط، وتُخلط على الخادم.
- مفتاح الإجابة لا يُرسل إلى المتصفح أبدًا، والتصحيح يتم بالكامل على الخادم.
- جلسات موقَّعة رقميًا (HMAC) + منع التسليم المكرر.
- تسجيل النتائج في Google Sheet مستقل مع عمودَي «المادة» و«الترم».
- روابط التواصل الاجتماعي (واتساب/فيسبوك/تيك توك) يديرها المدرس من لوحة التحكم،
  وتظهر للطلاب في أسفل الصفحة (الروابط المُفعّلة والصالحة فقط، بترتيب يحدده المدرس).
- لوحة تحكم من 7 أقسام: نظرة عامة، علم النفس، الفلسفة والمنطق، بنك الأسئلة، الامتحانات، النتائج، الإعدادات.
  - نظرة عامة: بطاقتا المادتين مع إحصائيات المحاولات والمتوسط.
  - علم النفس / الفلسفة والمنطق: إحصائيات المادة (ترمين للفلسفة) + هرم الامتحانات + سجل التدقيق + أحدث النتائج.
  - بنك الأسئلة: فلترة بالمادة/الترم/الفصل/التدريب/الصعوبة/حالة التحقق + بحث، والمفتاح يظهر للمدير فقط.
  - الامتحانات: هرم الامتحانات (بالترم) مع توزيع الصعوبة وحالة كل امتحان.
  - النتائج: سجل كامل (بالترم) مع فلترة بالمادة وتصدير CSV.
  - الإعدادات: الهوية والألوان ورمز الدخول وروابط التواصل الاجتماعي.

الأمان:
- التصحيح خادمي بالكامل؛ لا تُرسل الإجابات الصحيحة إلى المتصفح.
- لا يمكن تزوير جلسة امتحان (HMAC بمفتاح سرّي خاص بكل مشروع).
- واجهة الأدمن محمية برمز دخول، وبنك الأسئلة (مع المفتاح) لا يظهر إلا للمدير بعد الدخول.
- روابط التواصل تُعقَّم خادميًا: تقبل https:// فقط، وتُنزع منها وسوم HTML، وتُحد أطوالها
  (لا يوجد أي حقن HTML عبر الرابط أو الاسم الظاهر).
- كل بيانات المستخدم تُفلتر (HTML escape) قبل العرض.

التثبيت:
1) أنشئ مشروع Apps Script جديد.
2) أضف Code.gs وConfig.gs وData.gs وPhiloData.gs وPhiloTerm2Data.gs وIndex.html وAdmin.html بنفس الأسماء.
3) الصق محتوى الملفات كاملًا.
4) شغّل initializeSystem() مرة واحدة.
5) شغّل validateSystem() لعلم النفس، وvalidatePhiloSystem() لفلسفة الترم الأول،
   وvalidatePhiloTerm2System() لفلسفة الترم الثاني، وتأكد من النجاح.
6) انشر: Deploy > New deployment > Web app > Execute as Me > Who has access: Anyone.
7) افتح رابط /exec للطلاب، ونفس الرابط مع ?page=admin للإدارة.
   (تدعم اللوحة أيضًا ?mode=admin و ?admin=1)

نسخ القالب لمدرس آخر:
- انسخ مشروع Apps Script بالكامل إلى حساب/مشروع جديد.
- شغّل initializeSystem() في النسخة الجديدة وانشرها كـ Web App لرابط مستقل.
- افتح /exec?page=admin وسجّل بالـPIN (الافتراضي 1234) وغيّر بياناتك وروابط التواصل من اللوحة دون تعديل الكود.
- نتائج النسخة الجديدة تُحفظ في ملف Google Sheet مستقل.
