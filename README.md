# منصة الامتحانات التعليمية — exammanasa

منصة امتحانات إلكترونية عربية للفلسفة والمنطق (أولى ثانوي) وعلم النفس (ثانية ثانوي)، وفق المنهج الرسمي المصري ٢٠٢٦/٢٠٢٧.

> **٢٠٢٦-٠٩-٠٩:** أصبح للمنصة نسختان متكاملتان:
> - **المنصة السحابية الجديدة (الموصى بها للطلاب):** مجلد [`cloudflare/`](cloudflare/README.md) — Worker واحد على Cloudflare (خطة مجانية) يخدم كل المعلمين (`/<slug>`) مع لوحة تحكم بالبريد وكلمة المرور ومراجعة أسئلة بعد التسليم. اقرأ [دليل النشر](cloudflare/README.md).
> - **تطبيق Google Apps Script الأصلي:** يعمل كما هو (راجع `README.txt`) — ويستقبل أيضًا نتائج المنصة الجديدة في جدول النتائج نفسه عبر `doPost`.

## المحتوى
- **١٥٤٩ سؤالًا فريدًا / ٨٣ امتحانًا**: علم النفس (٤٧٤ سؤالًا، ٦ وحدات × ٤ موضوعات + شامل لكل وحدة + شامل المنهج كاملًا) والفلسفة والمنطق (١٠٧٥ سؤالًا عبر الترمين بهيكل الوحدات/الفصول الرسمية — منهما ٢٠٢ سؤال منطق للترم الثاني).
- كل الأسئلة من مصادر رسمية (كتب الشرح وكتب الأسئلة المقدمة) وبمفاتيح متحققة — التفاصيل الكاملة في تقارير التدقيق.

## الأدوات
```bash
# من جذر المستودع
node tools/build-banks.mjs      # توليد cloudflare/src/data/banks.json من ملفات .gs (بلا تعديلها)
node tools/validate-banks.mjs   # بوابة التحقق الكاملة (تفشل عند أي انحراف)

# من مجلد cloudflare/
npm install && npm run dev      # خادم محلي
npm test                        # ٥٨ اختبارًا شاملًا
npx wrangler deploy             # النشر (بعد ضبط KV — انظر الدليل)
```

## الأمان
التصحيح على الخادم فقط؛ مفاتيح الإجابة لا تُرسل للمتصفح قبل التسليم مطلقًا؛ جلسات موقّعة؛ لوحة التحكم بكلمة مرور مشفّرة PBKDF2. لا تضع أي أسرار في الملفات — استخدم `wrangler secret` وإعدادات مشروع Apps Script.
