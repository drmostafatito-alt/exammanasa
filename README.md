# منصة الامتحانات التعليمية — exammanasa

منصة امتحانات إلكترونية عربية للفلسفة والمنطق (أولى ثانوي) وعلم النفس (ثانية ثانوي)، وفق المنهج الرسمي المصري ٢٠٢٦/٢٠٢٧.

> **2026-09-11:** المنصة السحابية تشمل الآن **منصة المعلمين الكاملة** — Worker واحد على Cloudflare (خطة مجانية): `/admin` للمالك فقط، `/teacher` رابط دخول ثابت لكل المعلمين (بلا أي تسجيل ذاتي)، و`/<slug>` رابط طلاب لكل معلم يُولَّد تلقائيًا من اسمه. الحسابات يُنشئها المسؤول فقط (PBKDF2 + إبطال خادومي للجلسات)، وكل نتيجة تُنسب خادوميًا لصاحب الرابط مع عزل تام بين المعلمين. راجع [`FINAL_TEACHER_PLATFORM_AUDIT.md`](FINAL_TEACHER_PLATFORM_AUDIT.md) و[دليل النشر](cloudflare/README.md).
> - **تطبيق Google Apps Script الأصلي:** يعمل كما هو (راجع `README.txt`) — ويستقبل أيضًا نتائج المنصة الجديدة في جدول النتائج نفسه عبر `doPost`.

## المحتوى
- **1887 سؤالًا فريدًا / 127 امتحانًا**: علم النفس (474 سؤالًا، 6 وحدات × 4 موضوعات + شامل لكل وحدة + شامل المنهج كاملًا) والفلسفة والمنطق (1413 سؤالًا عبر الترمين بهيكل الموضوع/الدرس/التدريب الرسمي — منهما 202 سؤال منطق للترم الثاني). علم النفس محمي ببصمة SHA-256 `8851437be887…` في بوابة التحقق.
- كل الأسئلة من مصادر رسمية (كتب الشرح وكتب الأسئلة المقدمة) وبمفاتيح متحققة — التفاصيل الكاملة في تقارير التدقيق.

## الأدوات
```bash
# من جذر المستودع
node tools/build-banks.mjs      # توليد cloudflare/src/data/banks.json من ملفات .gs (بلا تعديلها)
node tools/validate-banks.mjs   # بوابة التحقق الكاملة (تفشل عند أي انحراف)

# من مجلد cloudflare/
npm install && npm run dev      # خادم محلي
npm test                        # ١٨٥ تأكيدًا شاملًا (منصة + معلمون + عزل + أمان)
node ../tools/ui-qa.mjs         # ١١٥ فحص DOM/سلوك (يتطلب خادمًا يعمل)
npx wrangler deploy             # النشر (بعد ضبط KV — انظر الدليل)
```

## الأمان
التصحيح على الخادم فقط؛ مفاتيح الإجابة لا تُرسل للمتصفح قبل التسليم مطلقًا؛ جلسات موقّعة HttpOnly/Secure/SameSite=Strict مع **إبطال خادومي** (تغيير كلمة المرور/إعادة تعيين المسؤول/التعطيل تُسقط الجلسات فورًا)؛ كلمات مرور PBKDF2-120k بملح فريد ومقارنة زمن-ثابت؛ عزل تام لكل معلم على مستوى الخادم. لا تضع أي أسرار في الملفات — استخدم `wrangler secret` وإعدادات مشروع Apps Script.
