# الصيغة القياسية لاستيراد/تصدير الامتحانات — Exam Import/Export Format (v1)

هذا هو المرجع الرسمي لصيغة ملف الامتحان الذي تقبله منصة الامتحانات
(`platform: "exammanasa"`, `version: 1`). تُستخدم نفس الصيغة للاتجاهين:

- **التصدير**: `لوحة التحكم ← الامتحانات ← تصدير JSON` (أو `GET /api/admin/exams/:id/export`).
- **الاستيراد**: `لوحة التحكم ← استيراد/تصدير ← رفع ملف` (معاينة ثم تأكيد صريح).

> القاعدة الذهبية: **لا يُحفظ شيء قبل المعاينة والتأكيد**، و**لا يُلمس بنك الأسئلة الأصلي إطلاقًا** —
> كل ما يُنشأ بالاستيراد يُخزَّن في «طبقة فوقية» (overlay) في KV تحت المفتاح `content:overrides`.
> لذلك يبقى فرق البنك (bank diff) = 0 بعد أي عملية استيراد.

---

## 1) الملف

| البند | القيمة |
| --- | --- |
| الترميز | UTF-8 (JSON نصي، بلا BOM) |
| الامتداد | `.json` (الواجهة تقبل `.json` / `application/json` فقط) |
| الحد الأقصى للحجم | 5 ميجابايت في المتصفح — 6 ميجابايت على الخادم (413 بعدها) |
| البنية | كائن JSON واحد فيه `exam` و `questions` (مصفوفة). المصفوفة في الجذر مرفوضة. |
| الحقول غير المعروفة | تُتجاهل بهدوء (لا تُعتبر خطأ) — ما عدا ما يُذكر أدناه |
| `version` | `1` فقط. غائب أو `null` ← يُعامل كـ`1`. أي رقم/نص آخر = **خطأ** (`errors[].where = "version"`) — لأن الإصدار إعلان للصيغة نفسها وليس حقلًا مجهولًا، فقبول إصدار غير معروف قد يستورد دلالات مختلفة بلا تحذير |

### مثال كامل (قابل للاستيراد مباشرة)

```json
{
  "version": 1,
  "exam": {
    "title": "امتحان فلسفة — الوحدة الأولى (مراجعة)",
    "subject": "الفلسفة والمنطق",
    "term": "الترم الأول",
    "grade": "الصف الأول الثانوي"
  },
  "questions": [
    {
      "text": "الفيلسوف الذي ربط السعادة بتحقيق الوظيفة العقلية للإنسان هو:",
      "options": {
        "A": "سقراط",
        "B": "أرسطو",
        "C": "ماركس",
        "D": "ديكارت"
      },
      "correctAnswer": "B"
    },
    {
      "text": "المنطق الرمزي يعتمد على:",
      "options": ["اللغة الطبيعية", "الرموز والقواعد الشكلية", "الحدس فقط", "التجربة الحسية"],
      "correctAnswer": "B"
    }
  ]
}
```

نموذج جاهز للتنزيل من اللوحة: زر **«تنزيل نموذج JSON»** → `exam-template.json`.

## 2) `exam` — بيانات الامتحان

| الحقل | مطلوب؟ | النوع | القبول / التطبيع | التخزين |
| --- | --- | --- | --- | --- |
| `title` | **نعم** | نص | لا يمكن أن يكون فارغًا بعد `trim` | يُقتطع إلى 200 حرف |
| `subject` | **نعم** | نص | `علم النفس` / `psychology` / `psych` (حالة الأحرف غير مهمة) ← `psychology`؛ `فلسفة` / `philosophy` / `philo` ← `philosophy`. أي قيمة أخرى = **خطأ** | `subjectId` |
| `subjectId` | بديل | نص | يُقرأ فقط إذا غاب `subject` | `subjectId` |
| `term` | لا | رقم/نص | يحتوي `2` أو `الثاني` ← `2`؛ وإلا ← `1`؛ `null`/`""` ← `null` | `term` |
| `grade` | لا | نص | ≤ 80 حرفًا | `grade` + `meta.lesson` للأسئلة الجديدة |
| `id` | — | نص | **يُتجاهل عند الاستيراد** (يظهر في التصدير فقط) — يُنشأ معرف جديد دائمًا | — |

الامتحان المستورد يُنشأ بالخصائص: `custom: true`, `type: "custom"`, `enabled: true`,
`unitTitle: ""`, `lessonTitle: ""`, `questionIds: [...]`, `createdAt/updatedAt` بتوقيت ISO،
ومعرّف فريد بصيغة `CX-XXXX` (لا يصطدم بمعرّفات البنك الأصلية).

## 3) `questions[]` — الأسئلة

| الحقل | مطلوب؟ | القبول |
| --- | --- | --- |
| `text` | **نعم** | نص السؤال؛ فارغ = خطأ؛ أطول من 3000 حرف = خطأ |
| `options` | **نعم** | **كائن** بالمفاتيح `A,B,C,D` **أو مصفوفة من 4 عناصر** (الترتيب A→D). العدد ≠ 4 = خطأ؛ أي خيار فارغ = خطأ؛ تكرار خيارين متطابقين داخل السؤال = **تحذير** (لا يمنع الاستيراد) |
| `correctAnswer` | **نعم** | `A` أو `B` أو `C` أو `D` (حالة الأحرف غير مهمة، تُرفع تلقائيًا). يُقبل أيضًا المفتاح البديل `answer`. أي قيمة أخرى = خطأ |
| `meta` | — | **يُتجاهل عند الاستيراد** (يظهر في التصدير فقط) |

السجل الذي ليس كائنًا = خطأ (`السجل ليس كائنًا صالحًا`).

الأسئلة الجديدة تُخزَّن بصيغة البنك الداخلية:

```json
{
  "id": "CQ-1A2B",
  "custom": true,
  "text": "…",
  "options": ["…", "…", "…", "…"],
  "answer": "B",
  "meta": {
    "subject": "الفلسفة والمنطق",
    "subjectId": "philosophy",
    "term": 1,
    "lesson": "الصف الأول الثانوي",
    "source": "استيراد من ملف (لوحة التحكم)",
    "verificationStatus": "imported"
  },
  "createdAt": "2026-09-12T21:40:00.000Z"
}
```

`verificationStatus: "imported"` يجعل الأسئلة المستوردة قابلة للفرز في «بنك الأسئلة»
لمراجعتها قبل الاعتماد، ولا تُخلط أبدًا بالأسئلة المُحقَّقة في البنك الأصلي.

## 4) مطابقة الأسئلة ومنع التكرار (dedupe)

قبل أي حفظ، يُحسب لكل سؤال **بصمة نص** (fingerprint) بالتطبيع التالي:

1. حذف التشكيل وعلامات المدّ والتطويل (`U+064B–U+0652`, `U+0670`, `U+0640`).
2. ضغط كل المسافات (بما فيها `U+00A0`) إلى مسافة واحدة.
3. حذف علامات الترقيم: `. , ، ؛ : ! ? ؟ ( ) " « » ' -` والتطويل.
4. `trim`.

ثم تُقارن البصمة بـ:

- **فهرس البنك كاملًا** (الأسئلة الأصلية + أسئلة الطبقة الفوقية) → حالة `exists`.
- **بقية أسئلة الملف نفسه** → حالة `duplicate-file`.

| الحالة | المعنى | ماذا يحدث عند الالتزام (commit) |
| --- | --- | --- |
| `new` | بصمة غير موجودة إطلاقًا | يُنشأ سؤال جديد `CQ-XXXX` ويُضاف للامتحان |
| `exists` | نفس نص السؤال موجود في البنك | **يُربط السؤال الموجود بمعرّفه** — لا يُنشأ نسخة مكررة |
| `duplicate-file` | تكرار داخل الملف نفسه | يُضاف **مرة واحدة** (أول ظهور يفوز)، والباقي يُتجاهل مع تحذير |
| `invalid` | فيه خطأ تحقق واحد على الأقل | **يُرفض** ولا يُستورد |

إعادة الفحص تتم **مرة ثانية على الخادم** لحظة الالتزام (race-safe): إن ظهر تطابق مع البنك
بين المعاينة والالتزام، يُربط السؤال الموجود بدل إنشاء جديد.

> **مهم:** الخيارات والإجابة الصحيحة **ليست** جزءًا من البصمة. المطابقة على نص السؤال فقط،
> تنفيذًا لمبدأ «تفضيل ربط الأسئلة الموجودة على تكرارها». إن كان نفس النص في البنك بإجابة مختلفة،
> سيُربط سؤال البنك كما هو — راجع صف المعاينة (`موجود بالفعل`) قبل التأكيد.

## 5) مسار الاستيراد في الواجهة (إلزامي)

1. رفع/إفلات الملف (قراءة نصية UTF-8 في المتصفح).
2. **«معاينة وتحقق»** → `POST /api/admin/import/preview` → تقرير كامل **بدون أي حفظ**.
3. عرض التقرير: عدّادات (الإجمالي / جديد / موجود بالفعل / مكرر في الملف / غير صالح) +
   جدول صف-بصف مع النص والخيارات والإجابة والحالة وأسباب الرفض + قائمة الأخطاء والتحذيرات.
4. زر **«تأكيد الاستيراد»** يظهر فقط إذا كان `report.ok === true`، ويتطلب تأكيدًا صريحًا.
5. `POST /api/admin/import/commit` مع `confirm: true` → **إعادة تحقق كاملة على الخادم** →
   إنشاء الامتحان والأسئلة في الطبقة الفوقية.

استجابة الالتزام:

```json
{ "ok": true, "examId": "CX-9F2A", "createdQuestions": 12, "reusedQuestions": 8, "total": 20 }
```

## 6) الـ API (للتكامل الخارجي)

كلا الطرفين **خاص بالمسؤول فقط**:

- جلسة `admin_session` (كوكيز `HttpOnly; Secure; SameSite=Strict`) صالحة وغير مسحوبة.
- كل طلب غير `GET` يحتاج الترويسة `X-Requested-With: fetch` (حماية CSRF) — وإلا `403`.
- بدون جلسة → `401`.

```
POST /api/admin/import/preview
Content-Type: application/json
{ "text": "<محتوى ملف JSON كنص>" }            # أو "json": "<نص>"
→ 200 { "report": { ok, exam, stats, errors[], warnings[], rows[] } }

POST /api/admin/import/commit
Content-Type: application/json
{ "text": "<نفس المحتوى>", "confirm": true }   # confirm !== true → 400
→ 200 { ok, examId, createdQuestions, reusedQuestions, total }
→ 400 { "error": "لا يمكن الاستيراد: …" }      # إن فشل التحقق عند الالتزام

GET  /api/admin/exams/:id/export
→ 200 تطبيق/‍json كملف مرفق: exam-<id>.json    # Cache-Control: no-store
```

### بنية `report`

```jsonc
{
  "ok": true,                       // لا أخطاء && عدد الصفوف > 0
  "exam": { "title": "…", "subjectId": "philosophy", "term": 1, "grade": "…" },
  "stats": { "total": 20, "invalid": 0, "existsInBank": 8, "duplicateInFile": 0, "newCount": 12 },
  "errors":   [ { "where": "questions[3].correctAnswer", "message": "…" } ],
  "warnings": [ "السؤال 7: خيارات مكررة داخل السؤال نفسه." ],
  "rows": [
    {
      "index": 1,
      "text": "…",
      "options": { "A": "…", "B": "…", "C": "…", "D": "…" },
      "correctAnswer": "B",
      "status": "new",              // new | exists | duplicate-file | invalid
      "existingId": null,           // معرف سؤال البنك عند exists/duplicate-file
      "problems": []                // أسباب الرفض/التحذير لهذا الصف
    }
  ]
}
```

`errors[].where` يتبع مسارات دقيقة: `exam.title`, `exam.subject`, `questions`,
`questions[i].text`, `questions[i].options`, `questions[i].options.A`, `questions[i].correctAnswer`.

## 7) صيغة التصدير (نفس الملف، مع حقول إضافية للقراءة فقط)

```jsonc
{
  "version": 1,
  "platform": "exammanasa",
  "exportedAt": "2026-09-12T21:40:00.000Z",
  "exam": {
    "id": "T1-PH-01",              // يُتجاهل عند الاستيراد
    "title": "…",
    "subject": "الفلسفة والمنطق",   // اسم عربي للعرض
    "subjectId": "philosophy",
    "term": 1,
    "grade": "الصف الأول الثانوي",
    "type": "unit",
    "unitTitle": "…",
    "lessonTitle": "…"
  },
  "questions": [
    {
      "id": "Q-PH-0001",           // يُتجاهل عند الاستيراد (يُربط بالبصمة لا بالمعرّف)
      "text": "…",
      "options": { "A": "…", "B": "…", "C": "…", "D": "…" },
      "correctAnswer": "B",         // ⚠ مفتاح الإجابة — للمسؤول فقط
      "meta": { }                   // يُتجاهل عند الاستيراد
    }
  ]
}
```

الملف المصدَّر **قابل لإعادة الاستيراد مباشرة** (round-trip): سيُنشأ امتحان جديد
بمعرّف جديد، وتُربط كل أسئلته الموجودة في البنك دون أي تكرار.

> 🔒 **أمان:** `correctAnswer` و`meta` يخرجان فقط من نقاط `/api/admin/*` المصادَق عليها.
> الـ API العام (`/api/catalog`, `/api/exam/start`, `/api/teacher/:slug`) لا يحمل مفاتيح إجابة
> أو بيانات داخلية إطلاقًا، والتصحيح يتم على الخادم.

## 8) جداول البيانات (XLSX / CSV / Google Sheets)

المحلّل الحالي **JSON فقط** — لا يوجد اعتماد على مكتبة جداول بيانات في المتصفح أو في الـ Worker
(حزمة الواجهة بلا أطر، وهذا مقصود). للعمل من ملف جدول:

| عمود الجدول | الحقل في JSON |
| --- | --- |
| نص السؤال | `questions[i].text` |
| الخيار الأول / A | `options.A` |
| الخيار الثاني / B | `options.B` |
| الخيار الثالث / C | `options.C` |
| الخيار الرابع / D | `options.D` |
| الإجابة الصحيحة | `correctAnswer` (`A`/`B`/`C`/`D`) |

خطوات مقترحة (بدون أي كود في المنصة):

1. في Google Sheets / Excel: نظّم الأعمدة بالترتيب أعلاه، وصفًا واحدًا لكل سؤال، وورقة واحدة للامتحان.
2. احفظ/صدّر الورقة **CSV (UTF-8)** ثم حوّلها إلى JSON بأي محوّل، أو — الأسهل والأأمن —
   نزّل «نموذج JSON» من اللوحة والصق الأسئلة فيه.
3. ضع بيانات الامتحان مرة واحدة في `exam` (لا تكررها لكل صف).
4. ارفع الملف في اللوحة، راجع المعاينة صفًا بصف، ثم أكّد.

> لا تُصدّر جدولًا يحتوي أعمدة إضافية حساسة (مفاتيح داخلية، معرفات، ملاحظات تصحيح) وتعتبرها محذوفة
> تلقائيًا — الحقول غير المعروفة تُتجاهل، لكن **راجع المعاينة دائمًا** قبل التأكيد.

## 9) أخطاء التحقق الشائعة ورسائلها

| الرسالة | السبب | الإصلاح |
| --- | --- | --- |
| `الملف ليس JSON صالحًا…` | JSON مكسور أو ترميز غير UTF-8 | تحقق من الأقواس/الفواصل، احفظ بـ UTF-8 |
| `بنية الملف غير صحيحة: يُتوقع كائن JSON يحتوي exam و questions.` | الجذر مصفوفة أو قيمة بسيطة | غلّف الملف بكائن |
| `إصدار الصيغة غير مدعوم: «…» — المدعوم هو version: 1` | `version` برقم مختلف عن 1 | احذف الحقل أو اجعله `1` |
| `اسم الامتحان مطلوب (exam.title).` | عنوان فارغ | أضف `exam.title` |
| `المادة مطلوبة: «الفلسفة والمنطق» أو «علم النفس» (exam.subject).` | قيمة مادة غير معروفة | استخدم إحدى القيم المقبولة أعلاه |
| `لا توجد أسئلة في الملف (questions).` | مصفوفة فارغة/مفقودة | أضف سؤالًا واحدًا على الأقل |
| `عدد الأسئلة كبير جدًا (الحد 200 سؤال لكل امتحان).` | أكثر من 200 سؤال | قسّم الامتحان على ملفين |
| `عدد الخيارات N — المطلوب 4 بالضبط.` | 3 أو 5 خيارات | وحّد عدد الخيارات على 4 |
| `الإجابة الصحيحة يجب أن تكون A/B/C/D — الوارد: «…»` | إجابة نصية أو رقم (مثل `2` أو `ب`) | استخدم حرفًا لاتينيًا A–D |
| `لا يمكن الاستيراد: …` (عند الالتزام) | تغيّر الملف/البنك بعد المعاينة | أعد المعاينة ثم أكّد |

## 10) ما بعد الاستيراد (إدارة ومراجعة)

- الامتحان يظهر في **«الامتحانات»** بشارة `مخصّص` (وفلتر الحالة `مخصّص/مستورد`) ويمكن:
  تعطيله/تفعيله، تحرير عنوانه وبياناته، **إعادة ترتيب أسئلته**، إزالة سؤال منه، إضافة أسئلة من
  منتقي البنك، تصديره JSON، ثم حذفه (قابل للاستعادة من «المحذوفات»).
  زر «استعادة الأصل» (`revert`) يظهر للامتحانات **الأصلية/المعدَّلة** فقط — الامتحان المستورد
  كيان جديد في الطبقة الفوقية، لذا يُحذف/يُستعاد بدل إرجاعه لأصل.
- الأسئلة الجديدة تظهر في **«بنك الأسئلة»** بفلتر `مضافة/مستوردة` (`only=custom`) ويمكن
  تحريرها/تكرارها/حذفها/استعادتها من السلة، أو **إرجاعها إلى الأصل** (`revert`) إن كان لها نظير أصلي.
- أي حذف/تعديل في الطبقة الفوقية **لا يعدّل ملف البنك المضمّن** (`src/data/banks.json`) —
  لذلك يبقى `npm run validate` و bank diff بلا تغيير بعد الاستيراد.
