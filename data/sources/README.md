# مصادر التحقق الرسمية (ضعها هنا)

هذا المجلد مخصص للمصادر التي تحسم مفاتيح الإجابة غير المحسومة (انظر `REVIEW_ANSWER_KEYS.md`):

1. كتاب الشرح الرسمي — الفلسفة والمنطق، الصف الأول الثانوي (PDF/DOCX)
2. نموذج الإجابة الرسمي لكتاب الأسئلة
3. كتاب الأسئلة الأصلي: `كتاب اسئلة الترم الاول فلسفة ومنطق (1).docx` و `كتاب اسئلة فلسفة الترم التاني (1).docx`

بعد إضافتها: تُحسم كل بنود `REVIEW_ANSWER_KEYS.md` بمرجع صفحة/فقرة، وتُسجَّل القرارات في
`data/key-decisions.json` بالصيغة `{ "questionId": { "answer": "B", "source": "كتاب الشرح ص 41", "note": "" } }`
ثم `node tools/build-banks.mjs && node tools/validate-banks.mjs`.
لا يُقبل قرار بلا مرجع مصدر.
